Cómo usar: selecciona un tramo de la lista o del mapa. Marca la casilla únicamente cuando hayas completado su sobrevuelo. Puedes buscar por kilómetro, filtrar pendientes y sobrevolados, arrastrar el mapa y centrar el tramo elegido. Usa “Mi ubicación” para activar el GPS del teléfono, ver el punto azul y su precisión, identificar el tramo más cercano y seguir tu posición. La geolocalización requiere permiso del navegador y, normalmente, una página servida mediante HTTPS o localhost; abrir el archivo HTML directamente puede no permitirla en algunos navegadores móviles. “Detener GPS” interrumpe el seguimiento. Tu posición no se incorpora a los respaldos JSON ni al HTML. Las marcas se guardan en este navegador si permite almacenamiento local. Exporta el JSON o descarga una copia HTML con tu avance como respaldo. Importar reemplaza el avance actual, con confirmación. También puedes descargar el polígono KML de cualquier tramo.
Datos: 22 polígonos consecutivos de 250 m (km 20–25.5), cauce + 35 m exteriores desde ambas orillas, aproximadamente ha en total. Coordenadas WGS84; dibujo y superficies UTM 19S (EPSG:32719), norte de cuadrícula. Se conserva como sobrevolado el tramo km 23.5–23.75 del HTML original; los diez tramos añadidos empiezan pendientes. Este mapa es un registro de áreas, no una misión automática de vuelo ni acredita cobertura fotogramétrica. Los enlaces a Drive requieren internet y permisos; el mapa y la descarga de KML funcionan sin conexión; el GPS depende de permisos y disponibilidad de posicionamiento. El seguimiento puede pausarse cuando el navegador pasa a segundo plano.
