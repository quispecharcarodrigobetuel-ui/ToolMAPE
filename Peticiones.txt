Quiero que construyas un módulo completo de scraping, enriquecimiento con GPT, labeling de mercado y publicación en Supabase para noticias que puedan afectar el precio del oro en soles por gramo.

## Contexto del proyecto

El sistema se llama Toolmape. Su objetivo es ayudar a mineros artesanales en Perú a decidir si conviene vender oro ahora o esperar. El precio objetivo del sistema es:

precio_oro_soles_gramo = (precio_oro_usd_oz / 31.1035) * tipo_cambio_usd_pen

Ya existe un pipeline de mercado con yfinance y modelos Random Forest de precio. Ahora quiero agregar señales sociopolíticas y macroeconómicas extraídas desde noticias.

## Objetivo técnico

Crear un pipeline local, automatizable y preparado para producción, que haga lo siguiente:

1. extraer listados de noticias desde fuentes configuradas,
2. normalizar títulos, URLs, fechas y resúmenes,
3. deduplicar noticias,
4. enviar cada noticia nueva a un GPT clasificador,
5. recibir una salida JSON estructurada,
6. guardar datos crudos y enriquecidos,
7. cruzar noticias con precios de mercado para generar labels a 1d y 3d,
8. generar features agregadas diarias,
9. publicar todo en Supabase usando upsert,
10. dejar el sistema listo para ejecutarse manualmente y luego automatizarse con GitHub Actions.

## Prompt GPT

Usa este prompt base:

Eres un analista macrofinanciero especializado en oro, dólar, tasas de interés, inflación, bancos centrales y riesgo geopolítico.

Tu tarea es clasificar una noticia económica o minera para un sistema llamado Toolmape, cuyo objetivo es estimar el impacto sobre el precio del oro en soles peruanos por gramo.

El precio objetivo final es:
precio_oro_soles_gramo = (precio_oro_usd_oz / 31.1035) * tipo_cambio_usd_pen

Debes analizar la noticia únicamente con la información proporcionada. No inventes datos. Si la noticia es ambigua o no tiene relación clara con oro, dólar, tasas, inflación, Fed, geopolítica, minería o tipo de cambio, clasifícala como impacto bajo o nulo.

Devuelve exclusivamente un JSON válido ajustado al esquema solicitado.

Reglas:

1. Si una noticia fortalece el dólar, normalmente presiona a la baja el oro en USD.
2. Si una noticia aumenta el riesgo geopolítico, normalmente favorece al oro como activo refugio.
3. Si una noticia indica tasas más altas por más tiempo, normalmente es bajista para oro.
4. Si una noticia indica recortes de tasas o dólar débil, normalmente es alcista para oro.
5. Para precio_oro_soles_gramo, considera tanto oro_usd_oz como usd_pen. Puede ser mixto si oro baja pero USD/PEN sube.
6. No des recomendaciones de inversión.
7. No afirmes certeza absoluta.

## Labeling de mercado

Implementa labeling a 1d y 3d.

El objetivo principal es `precio_oro_soles_gramo`.

Para cada noticia:

1. toma su fecha de publicación,
2. encuentra el precio de referencia disponible más cercano de la sesión correspondiente,
3. encuentra el precio 1 sesión después,
4. encuentra el precio 3 sesiones después,
5. calcula:

* `return_1d`
* `direction_1d`
* `impact_class_1d`
* `return_3d`
* `direction_3d`
* `impact_class_3d`

Usa umbrales configurables:

Dirección:

* menor a -0.3% = bajista
* entre -0.3% y 0.3% = neutral
* mayor a 0.3% = alcista

Impacto:

* abs(return) < 0.3% = nulo
* 0.3% a 0.7% = bajo
* 0.7% a 1.5% = medio
* 1.5% a 2.5% = alto
* mayor a 2.5% = muy_alto

Los umbrales deben vivir en config.
